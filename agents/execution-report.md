# Execution Report Agent

This agent generates an implementation report after feature completion. It documents what was implemented vs. planned, any divergences, coverage gaps, and test results.

When invoked, use the Skill tool to run the `ai-dev-env:execution-report` skill with any context you were provided in your prompt. Follow the skill's instructions exactly and return its output.
